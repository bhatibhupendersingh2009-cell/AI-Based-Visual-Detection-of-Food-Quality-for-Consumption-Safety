# 🍎 Food Quality Detection

---

## 📘 Project Overview

An AI-powered Food Quality Detection system built using Python, TensorFlow, and Streamlit. The application analyzes food images and classifies them as Fresh or Spoiled using Deep Learning and Computer Vision techniques.

---

## 🚀 Features

- Fresh vs Spoiled Food Classification
- Image Upload Interface
- Real-Time AI Prediction
- Confidence Score Display
- Modern Streamlit Dashboard

---

## 🛠️ Tools Used

- Python
- TensorFlow / Keras
- CNN (Deep Learning)
- NumPy
- Streamlit
- Pillow (PIL)

---

## 📊 Project Insights

- Automated food quality assessment
- Fast and reliable predictions
- Supports food safety and waste reduction
- User-friendly AI application

---

## 🎯 Conclusion

This project demonstrates the use of Artificial Intelligence and Computer Vision for food quality inspection, providing accurate and efficient freshness detection through an interactive dashboard.
